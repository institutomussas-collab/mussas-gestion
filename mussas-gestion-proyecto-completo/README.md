# Mussas Gestión - Aplicación Web A Medida

Sistema integral para la gestión del estudio de danza **Mussas** (Valentín Alsina).

## Estructura del Proyecto
- **Módulo 1:** Alumnos, Ficha Médica y Avisos por WhatsApp.
- **Módulo 2:** Clases, Profesores y Toma de Lista Rápida.
- **Módulo 3:** Cobros, Pases, Recargo del 4% en Transferencias y Recibos por Wsp.
- **Módulo 4:** Caja Diaria y Liquidación de Sueldos Docentes.

## Paso a paso para subir a GitHub y Vercel:
1. Extraer el contenido de este ZIP.
2. Crear un repositorio en GitHub llamado `mussas-gestion`.
3. Subir todos estos archivos al repositorio.
4. Conectar GitHub con Vercel para hacer el Deploy automático.
